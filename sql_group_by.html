📊 Практическая работа: GROUP BY в SQLite

Цель работы:

Научиться использовать оператор GROUP BY для группировки данных и применения агрегатных функций в SQLite.

Что вы узнаете:

  • Создание таблиц с данными
  • Группировка данных по различным полям
  • Использование агрегатных функций: COUNT, SUM, AVG, MIN, MAX
  • Применение HAVING для фильтрации групп

📚 Теоретическая справка

Синтаксис GROUP BY:

SELECT столбец1, АГРЕГАТНАЯ_ФУНКЦИЯ(столбец2)
FROM таблица
GROUP BY столбец1
HAVING условие;

Агрегатные функции:

  • COUNT() - подсчитывает количество записей
  • SUM() - вычисляет сумму значений
  • AVG() - вычисляет среднее значение
  • MIN() - находит минимальное значение
  • MAX() - находит максимальное значение

🚀 Задание 1: Создание таблицы

Задание:

Создайте таблицу employees (сотрудники) со следующими полями:

  • id - целое число, первичный ключ
  • name - текст (имя сотрудника)
  • department - текст (отдел)
  • position - текст (должность)
  • salary - целое число (зарплата)
  • hire_date - текст (дата приема на работу)

Решение:

CREATE TABLE employees (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    department TEXT NOT NULL,
    position TEXT NOT NULL,
    salary INTEGER NOT NULL,
    hire_date TEXT NOT NULL
);

💰 Задание 4: Средняя зарплата по отделам

Задание:

Рассчитайте среднюю зарплату в каждом отделе. Отсортируйте результат по убыванию средней зарплаты.

💡 Подсказка: Используйте AVG() и ORDER BY 
SELECT department, 
       ROUND(AVG(salary), 2) as avg_salary
FROM employees
GROUP BY department
ORDER BY avg_salary DESC;

📅 Задание 8: Группировка по году

Задание:

Выведите количество сотрудников, принятых на работу в каждом году.

💡 Подсказка: Используйте функцию strftime('%Y', hire_date) для извлечения года из даты 
SELECT strftime('%Y', hire_date) as hire_year,
       COUNT(*) as employee_count
FROM employees
GROUP BY strftime('%Y', hire_date)
ORDER BY hire_year;

🏆 Задание 9: Отделы с высокой средней зарплатой

Задание:

Выведите отделы, где средняя зарплата выше 75000 рублей, и отсортируйте по убыванию средней зарплаты.

SELECT department,
       ROUND(AVG(salary), 2) as avg_salary
FROM employees
GROUP BY department
HAVING AVG(salary) > 75000
ORDER BY avg_salary DESC;

📋 Итоговая проверка

Контрольные вопросы:
  1. В чем разница между WHERE и HAVING?
  2. Можно ли использовать GROUP BY без агрегатных функций?
  3. Как отсортировать результаты группировки?
  4. Можно ли группировать по нескольким полям одновременно?
  5. Какие агрегатные функции вы использовали в этой работе?

Ответы на контрольные вопросы:

  1. WHERE фильтрует строки до группировки, HAVING фильтрует группы после группировки.
  2. Да, GROUP BY можно использовать без агрегатных функций, но это имеет ограниченный смысл.
  3. Да, с помощью ORDER BY после GROUP BY.
  4. Да, можно указывать несколько полей через запятую в GROUP BY.
  5. COUNT, SUM, AVG, MIN, MAX.
