Функция map

Применяет функцию к каждому элементу последовательности (или к элементам нескольких последовательностей парами). Удобна для преобразования данных без явного цикла for.

Идея и синтаксис

map(функция, iterable_1, iterable_2, ...)

Для каждого элемента (или для каждой «кортежной» группы из нескольких списков) Python вызывает функция(элемент) и отдаёт результат. Функция может быть:

  • именованная через def;
  • lambda;
  • встроенная или метод типа (int, str.strip, str.upper).

Базовый пример

nums = [1, 2, 3, 4]
squares = map(lambda x: x ** 2, nums)
print(list(squares))   # [1, 4, 9, 16]

→ [1, 4, 9, 16]

Именованная функция

def add_ten(x):
    return x + 10

values = [1, 2, 3]
print(list(map(add_ten, values)))   # [11, 12, 13]

Объект map и ленивость

В Python 3 map возвращает итератор, а не список. Вычисление идёт по мере перебора (for, list(), next()). 

it = map(str.upper, ["hi", "sql"])
print(next(it))   # 'HI'
print(next(it))   # 'SQL'
print(list(it))   # [] — элементы кончились
Итератор map одноразовый: после полного прохода повторно в список не соберётся. Нужен снова — вызовите map(...) заново. 
# Частый паттерн — сразу материализовать:
result = list(map(int, ["10", "20", "30"]))

Варианты использования

1. Встроенные функции и методы

# строки → числа
prices = ["199", "50", "1200"]
print(list(map(int, prices)))   # [199, 50, 1200]

# обрезка пробелов
raw = ["  a", "b  ", " c "]
print(list(map(str.strip, raw)))   # ['a', 'b', 'c']

# регистр
print(list(map(str.lower, ["SQL", "Python"])))   # ['sql', 'python']

2. Lambda для простого преобразования

temps_c = [0, 20, 36.6]
temps_f = map(lambda c: c * 9 / 5 + 32, temps_c)
print(list(temps_f))

3. Функция с дополнительной логикой

def grade_label(score):
    if score >= 90:
        return "A"
    if score >= 75:
        return "B"
    return "C"

scores = [88, 92, 61]
print(list(map(grade_label, scores)))   # ['B', 'A', 'C']

4. map + zip: работа с парами (альтернатива двум iterable)

names = ["Anna", "Boris"]
bonuses = [500, 700]
# через map с двумя списками — см. следующий раздел
# или явно:
pairs = list(zip(names, bonuses))
print(list(map(lambda p: f"{p[0]}: +{p[1]}", pairs)))

5. Вызов метода экземпляра (осторожно с аргументами)

lines = ["hello", "world"]
# метод без аргументов — ок:
print(list(map(str.capitalize, lines)))   # ['Hello', 'World']

# если нужен аргумент метода — lambda или functools.partial:
print(list(map(lambda s: s.replace("l", "L"), lines)))

6. Объект с __call__ — тоже «функция» для map

class Doubler:
    def __call__(self, x):
        return x * 2

print(list(map(Doubler(), [1, 2, 3])))   # [2, 4, 6]

Несколько iterable

Если передать несколько последовательностей, map берёт элементы параллельно — как zip. Останавливается, когда заканчивается самая короткая. 

list(map(pow, [2, 3, 4], [3, 2, 5]))
# [2**3, 3**2, 4**5]  →  [8, 9, 1024]

list(map(lambda a, b: a + b, [10, 20], [1, 2, 3]))
# [11, 22]  — третья пара не используется
Для «распаковки» кортежей в функцию с несколькими параметрами удобнее itertools.starmap(func, iterable_of_tuples) — см. ниже.

map и list comprehension

map

Функция уже есть или встроенная (int, str.strip). Стиль «конвейер». Ленивый итератор.

[ ... for x in ... ]

Удобнее, когда логика длинная, нужен if внутри или читаемость важнее.

# Эквиваленты для квадратов:
list(map(lambda x: x ** 2, nums))
[x ** 2 for x in nums]

# Только comprehension (с условием):
[x ** 2 for x in nums if x % 2 == 0]
# map так не фильтрует — сначала filter, потом map, или одно comprehension

Рядом: filter, itertools

# filter — отбор, map — преобразование
nums = [1, 2, 3, 4, 5]
evens = filter(lambda x: x % 2 == 0, nums)
doubled = map(lambda x: x * 2, evens)
print(list(doubled))   # [4, 8]

# starmap — func(a, b) по кортежам
from itertools import starmap
points = [(1, 2), (3, 4)]
print(list(starmap(pow, points)))   # [1, 81]  если pow(1,2), pow(3,4)

Мини-задания

Задание 1

Из списка строк ["1", "2", "three", "4"] получите числа только там, где возможно, через map и обработку ошибок в своей функции (не через try в lambda без def).

def safe_int(s):
    try:
        return int(s)
    except ValueError:
        return None

data = ["1", "2", "three", "4"]
print([x for x in map(safe_int, data) if x is not None])   # [1, 2, 4]

Задание 2

Два списка: widths = [10, 20, 5], heights = [2, 3, 4]. Посчитайте площади прямоугольников через map с двумя iterable.

widths = [10, 20, 5]
heights = [2, 3, 4]
print(list(map(lambda w, h: w * h, widths, heights)))   # [20, 60, 20]

Задание 3

Перепишите без map на list comprehension и наоборот — что читается проще для вас?

words = ["sql", "db", "api"]
# map:
upper_map = list(map(str.upper, words))
# comprehension:
upper_comp = [w.upper() for w in words]
