CHECK в SQLite

Краткая шпаргалка: как задавать правила для данных прямо в таблице.

CHECK — ограничение, которое проверяет условие при INSERT и UPDATE. Если выражение ложно, SQLite отклоняет операцию. Это способ не дать в базу «балл 150» или статус «maybe».

Условие пишется в скобках после слова CHECK. Можно на уровне столбца или всей таблицы. Включите FK при отладке: PRAGMA foreign_keys = ON;

1. Диапазон числа

столбец Итоговый балл 0–100

CREATE TABLE enrollments (
    id INTEGER PRIMARY KEY,
    student_id INTEGER NOT NULL,
    score INTEGER CHECK (score >= 0 AND score <= 100)
);

Разрешить «ещё не сдано» через NULL (CHECK не срабатывает на NULL):

score INTEGER CHECK (score IS NULL OR (score >= 0 AND score <= 100))

2. Список допустимых значений

столбец Статус записи на курс

CREATE TABLE enrollments (
    id INTEGER PRIMARY KEY,
    status TEXT NOT NULL
        CHECK (status IN ('active', 'completed', 'dropped'))
);
Аналог «перечисления» без отдельной таблицы-справочника — удобно в учебных проектах.

3. Логическое поле (0 / 1)

столбец Флаг «курс пройден»

CREATE TABLE courses (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    is_published INTEGER NOT NULL DEFAULT 0
        CHECK (is_published IN (0, 1))
);

4. Связь двух столбцов

таблица Дата окончания не раньше начала

CREATE TABLE cohorts (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    start_date TEXT NOT NULL,
    end_date TEXT NOT NULL,
    CHECK (date(end_date) >= date(start_date))
);

Даты в формате YYYY-MM-DD — функция date() сравнивает их корректно.

5. Цена и скидка

таблица Скидка не больше базовой цены

CREATE TABLE promotions (
    id INTEGER PRIMARY KEY,
    base_price REAL NOT NULL CHECK (base_price > 0),
    discount REAL NOT NULL DEFAULT 0,
    CHECK (discount >= 0 AND discount <= base_price)
);

6. Текст: минимальная длина

столбец Email не пустой и с символом @

CREATE TABLE students (
    id INTEGER PRIMARY KEY,
    email TEXT NOT NULL
        CHECK (length(trim(email)) > 0 AND instr(email, '@') > 1)
);
Для production-email лучше проверка в приложении; CHECK — базовая «сетка безопасности» в БД.

7. Несколько правил сразу

комбо Поток: места и запись

CREATE TABLE cohorts (
    id INTEGER PRIMARY KEY,
    max_seats INTEGER NOT NULL CHECK (max_seats > 0),
    enrolled_count INTEGER NOT NULL DEFAULT 0,
    CHECK (enrolled_count >= 0 AND enrolled_count <= max_seats)
);

Что увидите при ошибке

INSERT INTO enrollments (student_id, score) VALUES (1, 150);
-- Error: CHECK constraint failed

Мини-практика (2 минуты)

  1. Создайте таблицу reviews с полем rating (1–5) через CHECK.
  2. Вставьте оценку 4 — успех; оценку 0 — ошибка.
  3. Добавьте CHECK: комментарий либо NULL, либо не короче 10 символов.
CREATE TABLE reviews (
    id INTEGER PRIMARY KEY,
    rating INTEGER NOT NULL CHECK (rating BETWEEN 1 AND 5),
    comment TEXT CHECK (
        comment IS NULL OR length(comment) >= 10
    )
);

INSERT INTO reviews (rating, comment) VALUES (4, 'Отличный курс!');
INSERT INTO reviews (rating) VALUES (5);
-- INSERT INTO reviews (rating) VALUES (0);  -- CHECK constraint failed
